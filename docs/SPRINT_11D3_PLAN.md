\## §1 Scope Statement



Ship the first public release of the Valoris ODRM benchmark under MIT. The benchmark is the open-source foundation layer of the dual-layer model: reproducible synthetic data, a validator external researchers can run without the backend, and a minimal baseline XGBoost model trained exclusively for the benchmark release.



\*\*Not in scope:\*\* the proprietary trained surrogate (stays internal), the TEA engine, the SaaS dashboard, the LangChain agent, the evidence chain. Those are commercial layers.



\*\*Why this release:\*\* the public-good tier promise (MIT foundation for Global South researchers, regulators, NGOs) requires an actual release artifact. A benchmark without a versioned tag and reproduction guide is not a release.



\## §2 Deliverables



\### §2.1 Dataset



\- Full 10,000-row dataset → GitHub Release asset `odrm\_benchmark\_10k.parquet` (\~1–2 MB).

\- 500-row sample → committed to repo at `benchmark/data/odrm\_sample\_500.parquet` (\~50–100 KB).

\- Generation seed documented: `SEED = 7` (matches README example).

\- Dataset generated by existing `scripts/generate\_odrm\_data.py` — no new generator.

\- Generation command (documented in `docs/BENCHMARK\_REPRODUCTION.md`):

&#x20; - \*\*Preferred:\*\* `python scripts/generate\_odrm\_data.py --n 500 --seed 7 --output benchmark/data/odrm\_sample\_500.parquet`

&#x20; - \*\*Fallback if `--output` flag absent:\*\* generate to default path, then move/rename, then re-run with `--n 10000` for the full set.

\- Schema: same as `backend/src/odrm/data/schema.py` (unchanged).

\- `benchmark/data/MANIFEST.json` records: generator script path, seed, row count, SHA-256 checksum of both files, generation timestamp.



\### §2.2 Validator CLI



\- `scripts/validate\_benchmark.py` — thin wrapper around `backend/src/odrm/data/schema.py`.

\- CLI: `python scripts/validate\_benchmark.py <path> \[--json]`.

\- Exit codes: `0` all rows valid, `1` validation failures, `2` invalid args / file missing.

\- Output: per-row errors plus summary (`{ "total": N, "valid": N, "invalid": N, "errors": \[...] }`).

\- Importable API: `validate\_file(path) -> ValidationReport`.

\- SPDX header: `# SPDX-License-Identifier: MIT`.



\### §2.3 Baseline model + training script



\- `benchmark/train\_baseline.py` — new MIT-licensed training script. \*\*Not a refactor of `backend/src/odrm/ml/train.py`\*\* (that stays proprietary).

\- Same algorithm (XGBoost), deliberately minimal: 200 trees, depth 4, learning rate 0.1 — enough to hit R² > 0.95 on the shipped data with sub-second training, not tuned for peak performance.

\- Fixed seed `SEED = 42` (documented in docstring and in `docs/BENCHMARK\_REPRODUCTION.md`).

\- Trains on `benchmark/data/odrm\_sample\_500.parquet` by default; `--data` flag for full dataset.

\- Outputs: `benchmark/artifacts/baseline\_model.json` (XGBoost native), `benchmark/artifacts/metrics.json` (R², RMSE per target).

\- SPDX header: `# SPDX-License-Identifier: MIT`.

\- Packaged as `benchmark/\_\_init\_\_.py` + `benchmark/train\_baseline.py` so importable.



\### §2.4 Reproduction documentation



\- `docs/BENCHMARK\_REPRODUCTION.md` — step-by-step:

&#x20; 1. Regenerate dataset (exact command, exact seed)

&#x20; 2. Validate (exact command, expected output)

&#x20; 3. Train baseline (exact command, expected metrics within tolerance)

&#x20; 4. Compare artifact to published checksum (what "reproducible" means in this context)

\- Declares expected metrics explicitly: `ch4\_conversion R² ≥ 0.95`, `syngas\_yield R² ≥ 0.95`, with tolerance band.

\- Declares non-reproducibility outside Python 3.11 / XGBoost pinned version — honest disclosure.



\### §2.5 Integration test inventory scaffold



\- `docs/INTEGRATION\_TESTS.md` — initial version listing D3's new tests plus existing integration tests (evidence export, whitelist, etc.). This is Audit Readiness item 3 evidence, and it does not exist yet. D3 starts it; Sprint 12 completes it.



\### §2.6 GitHub Release `v1.0-benchmark`



\- Tag: `v1.0-benchmark` (annotated).

\- Release notes: link to `docs/BENCHMARK\_REPRODUCTION.md`, dataset checksum, baseline metrics.

\- Assets: `odrm\_benchmark\_10k.parquet`, `baseline\_model.json`, `metrics.json`, `MANIFEST.json`.

\- MIT license declared in release body.

\## §5 Test Design



\### `test\_validate\_benchmark.py` (5 tests)



1\. `test\_validate\_sample\_all\_valid` — shipped 500-row sample returns 0 invalid.

2\. `test\_validate\_detects\_tampered\_row` — inject one invalid row, expect exit code 1 and error listing the row index.

3\. `test\_validate\_missing\_file\_exits\_2` — nonexistent path → exit 2.

4\. `test\_validate\_json\_output\_shape` — `--json` returns parseable JSON with the documented keys.

5\. `test\_validate\_uses\_backend\_schema` — assert CLI imports `odrm.data.schema` (no schema drift possible).



\### `test\_train\_baseline.py` (5 tests)



1\. `test\_train\_baseline\_on\_sample\_reproducible` — train twice with same seed; R² within 1e-4 both runs.

2\. `test\_train\_baseline\_artifact\_saved` — `baseline\_model.json` and `metrics.json` exist after training.

3\. `test\_train\_baseline\_meets\_threshold` — R² ≥ 0.95 for both targets on the sample.

4\. `test\_train\_baseline\_artifact\_loadable` — reload artifact with `xgboost.Booster.load\_model` succeeds.

5\. `test\_train\_baseline\_respects\_seed\_flag` — different `--seed` produces different metrics (sanity check).
